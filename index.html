🛡️ Honest by design

🔐 Built on Trust

We want HouseSplit to be useful without making promises we cannot prove. Here are two decisions behind this demo:

🎓 No unverified NCI endorsement

We did not say “Approved by NCI” because we have no evidence that the National College of Ireland has officially approved or endorsed HouseSplit.

🔒 No unsupported security claims

We did not say “Bank-grade security” because this early prototype has not been independently security-tested. It does not connect to a bank or process payments.

💜 This is a student demonstration using fictional data, not a live financial service.
